### `02` &nbsp; ON THE WORKBENCH

**🏎️ Easy Wheel** &nbsp; `PROTOTYPE`

An experimental project that turns a paper or cardboard wheel into a controller using a phone or webcam. The goal is to send steering to a virtual gamepad and try it with driving games.
